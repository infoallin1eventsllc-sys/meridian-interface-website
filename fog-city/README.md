# Fog City Roasters — brand site demonstration

The promotional website for a coffee brand identity, hosted by Meridian Interface as a
demonstration. Fog City Roasters is a fictional roaster.

    npm install
    DEMO_BASE=/demos/fog-city/ npm run build     # then copy dist/ to ../public/demos/fog-city/
    node ../tools/brand-demos.mjs                 # stamp the Meridian bar back on

The bundle this came from hotlinked ten images from a temporary AI Studio host; those now
point at the brand's own photographs, with small SVGs for the logo and avatar. Copy said
"Est. 1984" while the promotional artwork says "Est. 2013" — the artwork wins.
