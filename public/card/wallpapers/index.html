How to set a wallpaper

iPhone: tap a phone download, press and hold the picture, choose Save to Photos (or Add to Photos). Then Settings, Wallpaper, Add New Wallpaper, Photos.

Android: tap a phone download, open it from Downloads or Photos, then use the menu and choose Set as wallpaper.

Mac: download Laptop or Desktop, then System Settings, Wallpaper, Add Photo. Or right-click the file in Finder and choose Set Desktop Picture.

Windows: download Desktop or Laptop, right-click the file and choose Set as desktop background.
